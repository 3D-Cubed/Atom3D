# Atom3D Platform V1

Clean Vite/React starter for the Atom3D custom website/app platform.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL Vite gives you, usually:

```bash
http://localhost:5173
```

## Build

```bash
npm run build
```

## Vercel setup

1. Create a new GitHub repository.
2. Upload this project folder.
3. In Vercel, import the GitHub repo.
4. Framework preset: Vite.
5. Build command: `npm run build`.
6. Output directory: `dist`.
7. Deploy.

## Supabase

Supabase is not required for this V1 homepage. It will be added when we build the upload/quote/customer portal system.
